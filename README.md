# Abfragen BwR

Digitale Abfragen für den BwR-Unterricht an der bayerischen Realschule.

## Liefererskonto · BwR 8 (II)

**[Abfrage öffnen](https://tfeulner23.github.io/Abfragen-BwR/liefererskonto/)**

Sieben Aufgaben mit insgesamt 14 Punkten zu Liefererskonto, Nebenrechnung, Nachlasskonten, Buchungssatz und dem Vergleich von Rücksendung und Preisnachlass wegen Sachmängeln. Automatische Bewertung, Berücksichtigung von Folgefehlern, manuelle Punktekorrektur und PDF-Dokumentation.

Die vollständige HTML-Datei liegt unter `liefererskonto/index.html` und lässt sich auch herunterladen und offline im Browser öffnen. Eingaben bleiben nur während der geöffneten Sitzung erhalten. Vor dem Schließen die Ergebnis-PDF sichern. Es werden keine Schülerantworten an einen Server übertragen.

Alle Geschäftsfälle verwenden fiktive Daten des Modellunternehmens Courtline.
